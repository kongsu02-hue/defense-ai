실습 1. 표적 탐지와 임계값

AI가 정찰 영상에서 전차·장갑차를 찾고 신뢰도를 매깁니다. 임계값을 넘은 것만 '표적'으로 보고됩니다.

  1. 임계값 0.50에서 정밀도·재현율을 기록하세요.
  2. 0.20과 0.80으로 바꿔 오경보·미탐 수를 비교하세요.
  3. '기상 악화'를 켜고 같은 임계값에서 다시 측정하세요.
  4. 탐지 박스를 눌러 확대 영상을 보고 확인·기각하세요.

실습 2. 차량 예측정비

과거 정비 기록 400건으로 '30일 내 고장' 예측 모델을 학습시키고, 정비 슬롯 4개를 차량 12대 중 어디에 배정할지 결정합니다.

  1. 사용할 센서를 고르고 '모델 학습'을 누르세요.
  2. 학습 곡선과 센서별 영향도를 확인하세요.
  3. 차량 4대를 골라 정비를 배정하세요.
  4. '30일 운용'으로 결과를 보고 AI 추천과 비교하세요.

실습 3. 데이터 오염과 적대적 공격

레이더 반사 강도와 이동 속도로 표적/비표적을 구분하는 분류기(k-최근접 이웃)입니다. 공격자가 학습 데이터나 입력을 조작하면 어떻게 될까요?

  1. 오염 0%에서 기준 정확도를 기록하세요.
  2. 무작위 라벨 오염을 10%, 30%로 올려보세요.
  3. '표적형 오염'으로 바꿔 같은 비율에서 비교하세요.
  4. 적대적 섭동을 키운 뒤 '데이터 정제'를 켜보세요.

정리 질문

무작위 오염보다 표적형 오염이 적은 양으로도 표적 탐지율을 더 크게 떨어뜨리는 이유는 무엇일까요? 데이터 정제가 막아주는 공격과 막지 못하는 공격을 구분해 보세요.

실습 4. AI 결심지원 시나리오

가상 상황 6개에서 AI가 추천과 신뢰도, 근거를 제시합니다. 지휘관 입장에서 승인·보류·거부 중 하나를 고르세요.

  1. 상황과 AI 근거를 읽으세요.
  2. 필요하면 '추가 정보 요청'으로 확인하세요.
  3. 판단을 고르고 해설을 읽으세요.
  4. 마지막에 나의 판단 성향을 확인하세요.
