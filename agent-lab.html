AI 에이전트

말로 시키면 앱을 만들고, GitHub에 올리고, PC를 다루는 AI

에이전트는 대답만 하는 챗봇이 아니라 도구를 써서 일을 끝내는 AI입니다. 이 장에서는 실제로 쓰는 코딩 에이전트(Claude Code)를 다뤄 보고, 같은 원리를 Python 100줄로 직접 만들어 봅니다.

에이전트의 구조① 앱 개발② GitHub③ PC 제어안전 원칙설치·실행

에이전트의 구조: 목표 → 도구 → 관찰 → 반복

사용자 목표 ─▶ 모델이 다음 행동 결정 ─▶ 도구 호출 ──▶ 결과 관찰 ─┐
  "점검 앱 만들어"   (파일 쓰기? 테스트?)   │                     │
                                          ▼                     │
                              위험한 도구면 🛑 사람 승인          │

              ◀──────────── 목표 달성까지 반복 ◀──────────────────┘
모델

무엇을 할지 판단. 실습 코드는 Claude API(claude-opus-5-5)를 사용

도구

파일 읽기·쓰기, 명령 실행, git/gh, PowerShell. 무엇을 주느냐가 곧 권한

루프 · 하네스

도구 실행, 승인 요청, 기록, 최대 반복 제한을 맡는 코드 (agent_core.py)

① 앱 개발 에이전트

요구사항 → 파일 작성 → 테스트 실행 → 실패하면 수정 → 통과까지 반복. 미 국방부가 2026년 조달한 'CLI 에이전트형 코딩 도구'가 이 방식입니다.

실무 도구: Claude Code

cd C:\work\checklist
claude

  • 프로젝트 규칙은 CLAUDE.md에 적어 둔다 (예: "외부 라이브러리 금지, 테스트 필수, 실제 부대 정보 금지")

② GitHub 에이전트

저장소 상태 점검, 이슈 정리, 브랜치·커밋·초안 PR 작성, Actions 결과 확인을 맡깁니다.

바로 실행 (읽기)승인 후 실행 (쓰기)
repo_status, show_diff, read_file, list_issues, view_issue, list_prs, list_workflow_runs create_issue, comment_issue, create_branch, write_file, commit, push, create_pr(기본 초안)
python lab2_github_agent.py --repo C:\work\checklist "열린 이슈를 우선순위로 정리하고 가장 쉬운 것을 고칠 초안 PR을 만들어라"

시스템 프롬프트에 "main 직접 푸시 금지, 커밋에 'AI 에이전트 작성' 표시, diff로 비밀정보 확인"을 넣었습니다. 미 국방부 조달 조건인 AI 생성 코드 추적성을 Git 이력으로 구현하는 방법입니다.

③ 내 PC 제어 에이전트

"디스크 여유 공간이 얼마야?", "다운로드 폴더 정리해줘", "메모장 열어줘" 같은 지시를 PC 작업으로 바꿉니다.

도구동작승인
system_info, top_processesOS·메모리·디스크, 무거운 프로그램—
find_files, folder_summary홈 폴더 안 파일 검색·요약—
preview_organize폴더 정리 계획 미리보기 (옮기지 않음)—
organize_folder확장자별 하위 폴더로 이동, 되돌리기 기록 저장🛑
open_target웹 주소·파일·프로그램 열기🛑
run_powershell조회용 명령. 삭제·시스템 변경·외부 다운로드는 차단🛑
python lab3_pc_agent.py "PC 상태를 점검하고 다운로드 폴더 정리 계획을 보여줘. 실행은 하지 마."

삭제 도구는 일부러 주지 않았습니다. 에이전트의 실수는 도구 권한을 넘지 못합니다. 화면을 보고 마우스·키보드를 직접 조작하는 'computer use' 방식도 있지만, 권한이 훨씬 넓으므로 격리된 PC에서만 실습합니다.

안전 원칙 — 코드에 이렇게 구현되어 있습니다

🔐 최소 권한

실습마다 필요한 도구만 준다. 파일은 정해진 폴더, 명령은 허용 목록.

🛑 사람 승인

risky=True 도구는 실행 전 내용 표시 후 y/N. 거부하면 에이전트가 다른 방법을 찾는다.

🧾 기록·감사

모든 도구 호출을 logs/agent-날짜.jsonl에 남긴다.

👀 미리보기 후 실행

되돌리기 어려운 작업은 계획을 먼저 보여 주고, 삭제 대신 이동.

🔁 폭주 방지

최대 반복 횟수, 명령 시간 제한, 오류는 결과로 돌려줘 스스로 고치게.

🚫 민감정보 금지

실제 부대·작전·개인정보는 외부 AI에 넣지 않는다. 업무망에서는 승인된 체계만.
