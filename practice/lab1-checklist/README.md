# 실습 1. AI 코딩 에이전트로 웹앱 만들기 — 장비 점검 체크리스트

**목표:** 코드를 직접 쓰지 않고, 요구사항을 정확히 전달하고 결과를 검증하는 방식으로 업무용 웹앱을 완성한다.
**도구:** Claude Code(또는 `agent-labs/lab1_app_builder.py`), 브라우저 · **시간:** 90분

## 왜 이 실습인가

미 국방부는 2026년 2월 군·군무원 개발자용 AI 코딩 도구를 조달하면서 편집기 내 보조 도구와 함께
**터미널에서 여러 단계를 스스로 수행하는 CLI 에이전트**를 요구했고, 망분리(air-gapped) 배치와
**AI가 생성한 코드의 식별·추적**을 조건으로 걸었습니다. 이 실습은 바로 그 작업 방식을 연습합니다.

## 요구사항 (에이전트에게 줄 명세)

| 번호 | 요구사항 | 완료 기준 |
|---|---|---|
| R1 | 단일 `index.html` 파일, 외부 라이브러리·CDN 없음 | 인터넷을 끊어도 동작 |
| R2 | 점검 항목 템플릿 선택 (차량 일일점검 / 통신장비 / 발전기) | 템플릿을 바꾸면 항목 목록이 바뀜 |
| R3 | 항목별 `정상 / 이상 / 해당없음` 선택, 이상이면 조치 메모 필수 | 메모 없이 저장하면 경고 |
| R4 | 점검자·장비번호·일시 입력 후 저장, 브라우저 `localStorage`에 기록 | 새로고침해도 기록 유지 |
| R5 | 기록 목록과 '이상 있음' 필터 | 이상 기록만 볼 수 있음 |
| R6 | CSV 내보내기 | 엑셀에서 한글이 깨지지 않음 (UTF-8 BOM) |
| R7 | 휴대폰 화면에서 사용 가능 | 폭 360px에서 가로 스크롤 없음 |

## 진행 순서

1. 빈 폴더를 만들고 Claude Code를 연다.
   ```powershell
   mkdir C:\work\checklist; cd C:\work\checklist; claude
   ```
2. **계획 먼저:** 위 요구사항 표를 붙여 넣고 "코드를 쓰기 전에 화면 구성과 데이터 구조를 먼저 제안해줘"라고 요청한다.
3. 계획을 검토하고 고칠 점을 지시한 뒤 구현을 요청한다.
4. 브라우저로 열어 R1~R7을 **사람이 직접** 하나씩 확인한다. 실패한 항목은 재현 방법과 함께 다시 지시한다.
5. `git init` 후 커밋 메시지에 "AI 에이전트 작성, 사람 검증" 을 남긴다.

## 좋은 지시 vs 나쁜 지시

| 나쁜 지시 | 좋은 지시 |
|---|---|
| "점검 앱 만들어줘" | 요구사항 표 + 완료 기준 + 제약(단일 파일, 외부 라이브러리 금지) |
| "안 돼, 고쳐" | "R3: 이상 선택 후 메모 없이 저장하면 그대로 저장됨. 경고 후 저장을 막아야 함" |
| 결과를 읽지 않고 승인 | 변경 파일과 diff를 확인하고 승인 |
